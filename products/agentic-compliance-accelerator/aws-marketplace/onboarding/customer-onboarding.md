# Customer Onboarding

1. Subscribe through AWS Marketplace.
2. Open the Agentic Compliance Accelerator application.
3. Create or join an organization.
4. Select the compliance framework.
5. Configure the assessment.
6. Connect or upload relevant evidence.
7. Run the initial assessment.
8. Review identified gaps.
9. Generate documentation.
10. Execute remediation workflows.
11. Review readiness status.

## Marketplace SaaS fulfillment requirements
The production implementation must connect AWS Marketplace subscription/entitlement state to the customer account and plan entitlement lifecycle. Do not mark this gate complete until the production flow has been tested end-to-end.
