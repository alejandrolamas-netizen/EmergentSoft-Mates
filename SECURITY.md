# Security Policy

## Scope
This repository is part of the Alejandro Lamas / EmergentSoft technology portfolio.

## Reporting a vulnerability
Please do not disclose security vulnerabilities in public issues. Report suspected vulnerabilities privately through the repository owner or the official EmergentSoft contact channel.

Include the affected component, a concise description, reproduction steps where appropriate, and the potential impact.

## Security principles
- Never commit credentials, private keys, API tokens, certificates, or production secrets.
- Security-sensitive changes should be reviewed before entering the default branch.
- Proprietary architecture and implementation details should not be disclosed beyond what is intentionally published.

## Disclosure
Please allow reasonable time for investigation and remediation before public disclosure.
